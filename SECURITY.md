# Reporting a vulnerability

Contact support.cheeseteam@gmail.com privately with the affected feature, reproducible
steps using test accounts, expected and observed behavior, and a safe way to reply.
Do not include passwords, bearer tokens, production database dumps or private keys.
Do not post exploit details or other users' content in a public issue.

The current maintained product is the marketplace, forum, and their shared services.
The repository owner coordinates security triage, auth/database review and releases.
Content reports belong in the in-app Report flow or the support channel. Only
assigned Content Studio administrators may view confidential reports or take action.

Release evidence and outstanding operational requirements are tracked in
`docs/APP_STORE_REVIEW_REPORT_2026-09-11.md`. A green build is not an App Store approval.
